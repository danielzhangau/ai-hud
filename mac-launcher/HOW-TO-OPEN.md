# AI-HUD Config - macOS 使用说明

## 第一次打开（重要）

由于 macOS 安全机制（Gatekeeper），第一次打开必须用"右键 → 打开"：

1. 解压 `AI-HUD Config.app.zip`，得到 `AI-HUD Config.app`
2. 把 `AI-HUD Config.app` 拖到 `应用程序` 文件夹（或随便放在桌面也可以）
3. **右键单击** `AI-HUD Config.app`，选择 **"打开"**（不是双击）
4. 弹出警告："无法验证开发者..."，点击 **"打开"** 按钮
5. 完成 -- 浏览器会自动打开配置页面

之后每次使用：**直接双击** `AI-HUD Config.app` 即可。

## 日常使用流程

```
1. 用 USB 线把 AI-HUD 设备连接到 Mac
2. 等 5-10 秒（设备启动）
3. 双击 "AI-HUD Config.app"
4. 浏览器自动打开 → 可以修改设置
```

修改的设置会**实时保存**到设备并立即生效。

## 常见问题

### 双击后弹出 "无法打开..."

第一次打开请用 **右键 → 打开**，不是双击。详见上方"第一次打开"。

### 弹出 "未检测到 AI-HUD 设备"

- 检查 USB 线是否插好
- 等设备完全启动（约 30 秒）后再点
- 试一根**数据线**（很多 USB-C 线只能充电不能传数据）

### 弹出 "设备已连接但配置服务无响应"

设备的配置服务还没启动。

- 等 30 秒后再试
- 还不行：拔下 USB 线、等 5 秒、重新插上，再试

### 浏览器没自动打开

手动在浏览器地址栏输入：`http://localhost:8080`
